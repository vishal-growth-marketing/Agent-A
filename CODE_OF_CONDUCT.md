# Code of Conduct

## Our Commitment

Agent-A is committed to fostering an open, respectful, and collaborative community.

We welcome contributors from all backgrounds, experiences, and perspectives. Our goal is to create an environment where ideas can be shared, challenged, and improved through constructive discussion.

Every participant is expected to contribute to a positive and professional community.

---

# Our Standards

Examples of behavior that contribute to a positive environment include:

- Being respectful and professional.
- Welcoming different perspectives and experiences.
- Giving and accepting constructive feedback.
- Focusing discussions on ideas rather than individuals.
- Providing evidence and reasoning when making recommendations.
- Helping others learn and improve.
- Collaborating in good faith.

---

# Unacceptable Behavior

The following behaviors are not acceptable within the Agent-A community:

- Harassment or intimidation
- Personal attacks or insults
- Discrimination of any kind
- Hate speech or abusive language
- Trolling or intentionally disruptive behavior
- Spam or repeated off-topic discussions
- Deliberately misleading contributors
- Publishing private or confidential information without permission

These standards apply to Issues, Discussions, Pull Requests, and all other project communication channels.

---

# Community Guidelines

When contributing to Agent-A:

- Respect the project's architecture and governance.
- Discuss ideas openly and professionally.
- Explain the reasoning behind suggestions.
- Prefer collaboration over confrontation.
- Assume good intent from other contributors.

Healthy technical disagreement is encouraged. Personal conflict is not.

---

# Enforcement

Project maintainers are responsible for maintaining a welcoming environment.

Maintainers may:

- Request changes to contributions.
- Edit or remove inappropriate content.
- Close discussions that no longer contribute constructively.
- Restrict participation for repeated or serious violations of this Code of Conduct.

Enforcement decisions will be made fairly and in the best interest of the community.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please open a private GitHub discussion with the maintainers or contact the project owner directly.

Reports will be reviewed respectfully and handled as confidentially as possible.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- GitHub Discussions
- Project documentation
- Community discussions related to Agent-A
