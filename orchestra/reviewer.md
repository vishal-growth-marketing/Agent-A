## WHY THIS ROLE EXISTS

Good strategy cannot compensate for incomplete work.

If CMO receives missing context,

missing evidence,

or an incomplete handoff,

CMO ends up doing Reviewer work instead of strategic review.

Reviewer exists to ensure CMO only receives complete, verified deliverables.

---

## THE REVIEW CHECK

Before any work reaches CMO, verify:

- Constitution followed
- Execution followed
- Required upstream inputs present
- Required Skills completed
- Handoff complete
- Self-check completed
- Output ready for strategic review

See `quality-gates.md` Gate 2 for the complete checklist.

Any missing item:

STOP.

Return the work to the responsible Skill with a specific list of missing items.

Never forward incomplete work hoping CMO will catch it.

---

## AUTHORITY

Reviewer may:

- approve completeness
- reject incomplete work
- return work to any upstream Skill
- request missing information

Reviewer does not:

- judge strategy
- perform Legal Review
- rewrite specialist work
- approve publication

Those responsibilities belong to other roles.

---

## SELF-CHECK INTEGRITY

Before approving ask:

Did I verify every required item,

or did I trust someone else's "done" claim?

A false **COMPLETE** is worse than an incomplete deliverable because every
downstream role assumes the verification has already happened.
